# AI Passport 扫雷

为 FoloToy AI Passport 开发的离线三键扫雷游戏。开机直接进入初级新局。
灰色立体格、彩色数字、红色数码计数器和黄色笑脸参考经典 Windows 扫雷，
重新设计为适合 240 × 320 竖屏的界面。基于完整的
[AI Passport](https://gitee.com/FoloToy/ai-passport) ESP32-C3 项目复用 BSP，
不需要触摸屏、额外接线或联网。

![LVGL 软件渲染游戏预览](assets/images/minesweeper-preview.png)

软件渲染预览，电量为示例值；真实屏幕检查尚未执行。

## 规则与难度

| 难度 | 棋盘 | 雷数 |
| --- | --- | --- |
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 30 × 16 | 99 |

- 首次翻格及其周围八格无雷。首次翻格才布雷，提前插旗也不影响此保证。
- 空白格自动连锁展开；已插旗的格子不会被自动翻开。
- 翻开全部安全格即可获胜，不要求把雷全部插旗。胜利后剩余地雷自动插旗，计数器归零。
- 在已翻开的数字格上按确定，若邻近旗数等于数字，将快速展开其余邻格。错旗可能导致触雷。
- 失败后显示全部地雷，触发的雷标红，错旗划叉。胜利或失败后仍可移动光标查看棋盘。
- 剩余雷数为总雷数减旗数，可显示负数（三位显示最低为 -99）。首次翻格开始计时，菜单内暂停，结束后停止，最多显示 999 秒。
- 大棋盘使用自动滚动的 9 × 9 视窗，保持每格 22 像素；显示行列坐标及边缘滚动指示。
  采用经典随机布雷，可能需要猜测，不保证无猜解。

## 三键操作

| 按键 | 短按 | 双击 | 长按（500 毫秒） |
| --- | --- | --- | --- |
| 上 | 前一格 | 前一格 | 上一行，保持列 |
| 下 | 后一格 | 后一格 | 下一行，保持列 |
| 确定 | 翻格 / 数字格快速展开 | 插旗 / 取消旗 | 暂停菜单 |

逐格移动会跨行并在整盘首尾循环，换行在顶部/底部循环。方向键双击算一次移动。
确定的单击和双击由 BSP 的点击窗口区分，双击插旗不会先翻格。
三个按键共用 ADC 分压电路，因此不采用同时按多键的操作。

暂停菜单包含继续/查看棋盘、笑脸重开、选择难度和玩法帮助。
上/下选择，确定进入，长按确定返回。进行中的游戏重开或换难度时，
会出现默认选择“取消”的确认框。选择难度后开始对应的新局。帮助页短按或长按确定均可返回。

右上角显示电量；读取不可用时显示 `--%`。60 秒无操作自动暂停并降低背光，
120 秒后关闭背光。首次操作只恢复亮度，后续单击/长按事件被忽略；
选择“继续”后恢复游戏。无线和音频栈不启动。当前棋局、难度和记录仅保存在 RAM 中，
断电重启后开始初级新局。

## 构建与固件

使用 ESP-IDF **5.5.3**，目标为 **ESP32-C3 / 8 MB Flash / 无 PSRAM**。
先读 [AGENTS.md](AGENTS.md) 和[环境指南](docs/development/engineering/environment-setup.zh_CN.md)。
激活 IDF 后执行：

```bash
./tools/validate.sh --static
./tools/validate.sh
```

完整验证使用版本管理中的 `sdkconfig.defaults` 构建、验证合并镜像布局，
输出 `build/FoloToy-AI-Passport-full.bin`。它包含引导程序、分区表和应用，
从 **0x0** 刷写。匹配的 ELF/MAP 和校验值存于 `build/firmware/<sha256>/`，
使用 `python3 tools/archive_firmware.py verify <directory>` 校验。
生成固件和工具链不提交到 Git。

分区保持 NVS 位于 0x9000、PHY 位于 0xF000、单个 factory 应用位于 0x10000 并延伸至 8 MB 边界。
刷写合并镜像可能重置已有 NVS/PHY 数据。需要针对设备的明确刷机授权；
构建或推送 Git 不代表允许刷机。不要求整片擦除或备份原固件，详见[数据政策](docs/development/engineering/firmware-layout.zh_CN.md)。

## 验证与设备验收

主机测试覆盖 600 个随机棋盘、10 万次随机操作、精确雷数/邻接数、首击安全、
连锁展开、插旗、数字格快速展开、胜负、结束状态不可修改、移动、滚动、确认框、
计时与唤醒事件抑制。两套字体按固定界面字符清单检查；启动时还检查实际 LVGL 字形描述，
包含已知缺字的反向测试。字体材料与重生成方法见[资源说明](assets/README.zh_CN.md)。

通过独立的 LVGL **v9.5.0** 源码目录，可以生成实际 LVGL 软件渲染截图，并进行 300 次重绘内存压力检查：

```bash
cmake -S tests/lvgl_host -B build/preview -G Ninja \
  -DLVGL_SOURCE_DIR=/absolute/path/to/lvgl
cmake --build build/preview
mkdir -p build/screenshots
build/preview/minesweeper_preview build/screenshots
```

预览直接渲染应用代码，使用 24 KB LVGL 内存池和 40 行 RGB565 缓冲，
应用 BSP 圆角屏幕几何，输出 PPM 图片。该检查验证软件渲染，不能验证真实屏幕或 ADC 时序。

实机需检查启动稳定性和堆内存、各页中文字形、数字/旗/雷/光标可见性、
全部短按/双击/长按、高级棋盘四角滚动、首击安全、错旗快速展开、胜负、
暂停/继续/重开确认、电量降级和 60/120 秒闲置唤醒。
还需观察按键响应、LCD 显示并测量功耗。获准刷机并实际观察前，这些项目均未验证。
